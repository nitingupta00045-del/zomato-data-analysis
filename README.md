# 🍽️ Zomato Data Analysis

Welcome to the **Zomato Data Analysis** repository! This project hosts a comprehensive dataset containing details of restaurants, their locations, pricing, customer ratings, and cuisine offerings.

---

## 📌 Project Overview
The objective of this repository is to store and analyze restaurant data to uncover trends in the food and dining industry. The dataset provides valuable insights into customer preferences, price distribution, delivery services, and popular localities.
